Comienza comprobando Docker Desktop.

1. Preparar el equipo

Requiere Docker Desktop con motor Linux (WSL2). No se instala ni se cambia Docker sin intervención del técnico.

Archivos privados en los datos de esta aplicación. Local: puerto 15000; Frigate: 18971. No sustituye servicios existentes.

2. Empresa y sede

Seleccionar identificadores existentes evita duplicados. Completa un nombre para crear o modificar. La sede debe pertenecer a la empresa.

3. Conexiones de cámaras

    Al editar, deja las URLs vacías para conservarlas. Las cámaras V380 se configuran en el gestor local y requieren el puente Windows del fabricante.

    4. Exportar e instalar Frigate

    Planifica espacio de disco antes de activar la grabación. Las copias conservan configuración; no duplican grabaciones.

    La exportación conserva respaldo y rechaza modificaciones manuales o configuraciones de otra sede. Tras aplicar, espera el arranque y pulsa Verificar.

    5. Acceso y conexión con Vigilay Web

    La contraseña se envía por un canal privado a tu Frigate; no se guarda en la configuración ni se imprime en registros.

    El gateway saliente permite eventos y grabaciones sin dominio propio. El live remoto sigue requiriendo el agente de streaming instalado y activo; Desktop no lo reemplaza.
